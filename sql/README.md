# SQL Learning Journey

This directory contains the SQL projects I built while learning relational
database design and PostgreSQL.

The projects are designed manually without using any GUI tools or ORMs.
The goal is to understand how real-world databases are structured and how
tables relate to each other.

## Technologies

- PostgreSQL
- SQL
- psql
- Bash (for database automation)

## Projects

### Hospital Management System

A beginner-level hospital database designed manually.

Features:

- Departments
- Doctors
- Patients
- Appointments
- Admissions
- Wards
- Medicines
- Prescriptions
- Billing
